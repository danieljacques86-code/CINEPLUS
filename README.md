# IPTV Player CineVS

Player web que reproduz:
- `m3u8` (HLS)
- `mp4`
- `ts` (mpegts / Web HLS)

Carrega automaticamente uma playlist M3U do **Dropbox** (ex.: `m-sica.txt` / `sportLive.txt`) e atualiza a lista em intervalos fixos.
